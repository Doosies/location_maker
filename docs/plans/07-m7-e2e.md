## 왜 둘인가

CI 에서 실제 Kakao SDK 를 쓰면 테스트가 네트워크와 쿼터에 묶인다. 남의 서비스가 느린 날
우리 CI 가 빨개진다. 그래서 기본 저니는 SDK 를 가로채 고정 응답을 준다.

그런데 스텁만 있으면 **"우리 코드는 맞는데 SDK 계약이 바뀐"** 경우를 영영 못 잡는다.
그래서 진짜로 붙는지 확인하는 테스트를 하나 따로 두고, 수동으로 돌린다.

## 완료 조건

- [x] 실연동 테스트가 있고, CI 에서는 기본으로 제외된다 (`e2e-live.yml`, `workflow_dispatch`)

### 계획에서 달라진 것

**서버가 셋이다.** 키 주입이 빌드 타임이라 "키 있음" 과 "키 없음" 은 서로 다른 번들이다.
한 서버로는 둘 다 볼 수 없어 포트를 나눴다 — 4173 스텁, 4174 키 없음. 실연동은 따로 돌리며
(`pnpm test:e2e:live`) 그때만 4173 을 진짜 키로 빌드한 번들이 쓴다. Kakao 가 origin 을
포트까지 비교하므로 콘솔에 등록된 4173 을 벗어날 수 없다.
실연동 서버는 `E2E_LIVE=1` 일 때만 뜨고, 그때는 스텁·키 없음 쪽을 띄우지 않는다.
인자 철자가 아니라 환경변수로 고르는 것은, `--project live` 처럼 띄어 쓰면 서버와
프로젝트가 어긋나 엉뚱한 `ECONNREFUSED` 로 죽기 때문이다.

**스텁 서버는 자리를 채우는 키 값으로 빌드한다.** 키가 빈 문자열이면 로더가 아예 스크립트를
붙이지 않아 가로챌 것이 없어진다. 비밀이 아니고, 그 요청은 네트워크로 나가기 전에 스텁이
가로챈다.

**"키 없음" 저니를 따로 뒀다** (`LME-NOKEY`). 위 이유로 같은 파일에 둘 수 없다.

**테스트 파일은 `e2e/__tests__/` 아래에 둔다.** spec-sync 가 경로에 `__tests__` 마디가 있는
`*.test.ts` 만 테스트로 본다. 스펙은 저장소 관례대로 `__test_specs__/e2e/` 다.

**실연동은 CSV 로 좌표를 확인한다.** 진짜 지도의 마커에서는 좌표를 읽을 수 없다. CSV 가
같은 값을 그대로 내보내므로 그쪽으로 본다 — `x`/`y` 를 뒤집었으면 거기서 드러난다.

## 작업

### 1. SDK 스텁 — `e2e/fixtures/kakao-sdk-stub.ts`

`page.route('**/dapi.kakao.com/**')` 로 SDK 요청을 가로채, 최소한의 `kakao.maps` 객체를
심는 스크립트를 돌려준다.

- `Geocoder.addressSearch` — 고정 테이블. 없는 주소는 `ZERO_RESULT`
- `Places.keywordSearch` — 건물명 폴백 경로를 태우기 위한 최소 구현
- `Map` / `Marker` / `LatLngBounds` — DOM 에 흔적을 남겨 테스트가 셀 수 있게

### 2. 스텁 저니 — `e2e/paste-and-plot.spec.ts`

`prefix: LME-PLOT`. 스펙 문서는 `e2e/__test_specs__/paste-and-plot.spec.md`.

| 시나리오 | 확인 |
| --- | --- |
| 주소 5개 붙여넣고 표시 | 마커 5개, 목록 5줄, 순서 일치 |
| 못 찾는 주소 섞기 | 실패 항목이 원래 자리에 남고 마커는 그만큼 적다 |
| `고쳐서 다시` | 원문이 입력창에 돌아오고 재조회된다 |
| `중단` | 진행이 멈추고 남은 항목이 `pending` 으로 남는다 |
| `링크 복사` → 새 탭 | 같은 목록이 복원되고 자동 조회된다 |
| `CSV 내려받기` | 파일이 받아지고 줄 수가 입력 줄 수와 같다 |
| 키 없음 | 지도 자리에 안내 문구, 입력은 정상 동작 |

### 3. 실연동 — `e2e/live-kakao.spec.ts`

- `@live` 태그를 달고 CI 기본 실행에서 제외한다
- `VITE_KAKAO_JS_KEY` 가 없으면 **실패한다.** 조용히 건너뛰지 않는다
  (건너뛰면 초록이 신호가 아니게 된다)
- 확인 범위는 최소로: 주소 하나를 넣어 마커가 하나 뜨고 좌표가 한국 범위 안인지
- 쿼터를 축내지 않도록 주소 한두 개만 쓴다

### 4. CI 연결

- `ci.yml` 에 스텁 저니를 추가한다
- 실연동은 `workflow_dispatch` 로 수동 실행하는 잡으로 둔다
