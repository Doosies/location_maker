## 작업

### 1. URL 상태 — `src/share/url-state.ts`

`prefix: LM-URL`.

**주소 원문 목록만 URL 해시에 담는다. 좌표는 넣지 않는다.** 링크를 연 쪽이 다시 조회하면
되고, URL 이 짧아야 어디든 붙는다. 해시를 쓰는 이유는 GitHub Pages 가 경로 라우팅에 404 를
내기 때문이다 — 해시는 그 문제를 지나간다.

| 케이스 | 기대 |
| --- | --- |
| 주소 n개 → 인코딩 → 디코딩 | 원본과 같은 배열 |
| 한글 주소 | 깨지지 않는다 |
| 빈 목록 | 해시가 붙지 않는다 |
| 손상된 해시 | 예외를 던지지 않고 빈 목록으로 처리 |
| 아주 긴 목록 | 길이 상한을 두고, 넘으면 사용자에게 알린다 |

압축 여부는 구현 시 판단한다. 주소 20개 정도가 흔한 사용이므로 단순 인코딩으로 충분할
가능성이 높다. 넣기 전에 실제 길이를 재 보고 결정한다.

### 2. 복원

- 첫 렌더에서 해시를 읽어 입력창과 목록을 채운다
- 자동으로 조회를 시작한다 (사용자가 버튼을 또 누르게 하지 않는다)
- 조회 결과가 나와도 해시는 그대로 둔다 (좌표를 넣지 않기로 했으므로 바뀔 일이 없다)

### 3. CSV — `src/share/to-csv.ts`

`prefix: LM-CSV`.

열 구성:

| 열 | 내용 |
| --- | --- |
| `순번` | 1부터. 입력 줄 순서 |
| `입력값` | `raw` 그대로 |
| `상태` | 찾음 / 못 찾음 / 실패 |
| `주소` | 찾은 경우 정규화된 주소 |
| `건물명` | 있으면 |
| `위도` | 찾은 경우 |
| `경도` | 찾은 경우 |

| 케이스 | 기대 |
| --- | --- |
| 쉼표가 든 주소 | 따옴표로 감싼다 |
| 따옴표가 든 주소 | 이스케이프한다 |
| 줄바꿈이 든 값 | 따옴표로 감싼다 |
| 한글 | **BOM 을 붙인다.** 없으면 엑셀에서 깨진다 |
| 실패 항목 | 빠지지 않고 상태와 함께 들어간다 |

### 4. 내려받기

`Blob` + `URL.createObjectURL` + `<a download>`.
파일명에 날짜를 넣는다 (`location-maker-2026-09-11.csv`).
