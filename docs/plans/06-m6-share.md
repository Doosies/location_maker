### 계획에서 달라진 것

**`건물명` 열 대신 `도로명주소` 를 쓴다.** 어댑터가 들고 오는 것은 지번 주소(`label`)와
도로명 주소(`roadAddress`) 둘이고, 장소명으로 찾은 경우에만 `label` 이 상호가 된다.
없는 열을 만들기보다 있는 것을 그대로 내보낸다.

**해시는 base64url 로 담는다.** 퍼센트 인코딩은 한글 한 글자를 9자(`%EC%84%9C`)로 만든다.
시·도와 건물명이 붙은 실제 주소 20줄(원문 429자)이 퍼센트로는 **2887자**, base64url 로는
**1330자**다. 처음에 적었던 "700자" 는 인코딩 전 글자 수를 잰 것이어서, 그대로 뒀으면 흔한
사용(스무 줄 안팎)이 바로 상한에 막혔다.

**링크가 상한을 넘으면 자르지 않고 거절한다.** 몰래 자르면 주소 몇 개가 사라진 링크가
열리는데, 열리기는 하므로 사용자가 알아채기 어렵다. 상한은 **4000자** 로, 위 실측에서 잡았다
— 그런 주소 60줄 언저리까지 들어가고, 그보다 많으면 링크로 주고받을 크기가 아니다. 상한은
해시에만 건다.

**압축 라이브러리는 넣지 않았다.** base64url 은 `btoa` 와 `TextEncoder` 로 끝나므로
의존성이 늘지 않는다.

**자동 조회는 SDK 를 기다린다.** 키가 있는데 SDK 가 아직 없으면 가짜 어댑터가 답해 실제
주소가 전부 "못 찾음" 으로 찍힌다 (M5 리뷰에서 나온 것과 같은 함정이다). 준비된 뒤에 돈다.

## 작업

### 1. URL 상태 — `src/share/url-state.ts`

`prefix: LM-URL`.

**주소 원문 목록만 URL 해시에 담는다. 좌표는 넣지 않는다.** 링크를 연 쪽이 다시 조회하면
되고, URL 이 짧아야 어디든 붙는다. 해시를 쓰는 이유는 GitHub Pages 가 경로 라우팅에 404 를
내기 때문이다 — 해시는 그 문제를 지나간다.

| 케이스 | 기대 |
| --- | --- |
| 주소 n개 → 인코딩 → 디코딩 | 원본과 같은 배열 |
| 한글 주소 | 깨지지 않는다 |
| 빈 목록 | 해시가 붙지 않는다 |
| 손상된 해시 | 예외를 던지지 않고 빈 목록으로 처리 |
| 아주 긴 목록 | 길이 상한을 두고, 넘으면 사용자에게 알린다 |

압축 여부는 구현 시 판단한다. 주소 20개 정도가 흔한 사용이므로 단순 인코딩으로 충분할
가능성이 높다. 넣기 전에 실제 길이를 재 보고 결정한다.

### 2. 복원

- 첫 렌더에서 해시를 읽어 입력창과 목록을 채운다
- 자동으로 조회를 시작한다 (사용자가 버튼을 또 누르게 하지 않는다)
- 조회 결과가 나와도 해시는 그대로 둔다 (좌표를 넣지 않기로 했으므로 바뀔 일이 없다)

### 3. CSV — `src/share/to-csv.ts`

`prefix: LM-CSV`.

열 구성:

| 열 | 내용 |
| --- | --- |
| `순번` | 1부터. 입력 줄 순서 |
| `입력값` | `raw` 그대로 |
| `상태` | 찾음 / 못 찾음 / 실패 |
| `주소` | 찾은 경우 정규화된 주소 |
| `건물명` | 있으면 |
| `위도` | 찾은 경우 |
| `경도` | 찾은 경우 |

| 케이스 | 기대 |
| --- | --- |
| 쉼표가 든 주소 | 따옴표로 감싼다 |
| 따옴표가 든 주소 | 이스케이프한다 |
| 줄바꿈이 든 값 | 따옴표로 감싼다 |
| 한글 | **BOM 을 붙인다.** 없으면 엑셀에서 깨진다 |
| 실패 항목 | 빠지지 않고 상태와 함께 들어간다 |

### 4. 내려받기

`Blob` + `URL.createObjectURL` + `<a download>`.
파일명에 날짜를 넣는다 (`location-maker-2026-09-11.csv`).
