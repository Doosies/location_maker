# 지도 API 선택

**결정: Kakao Maps** (2026-09-11 승인)

주소를 여러 개 입력하면 지도에 마커로 찍어 주는 앱이다. 지도 렌더링과 주소→좌표
변환(지오코딩) 두 가지를 쓰고, 대상 주소는 한국 도로명·지번 주소가 중심이다.
후보 5종을 비용, 한국 주소 정확도, 백엔드 필요 여부로 비교했다.

## 왜 Kakao 인가

- 한국 도로명·지번 주소 정확도가 가장 높은 축이고, 건물명·상호 검색까지 같은 API로 된다.
- JS SDK 의 `services.Geocoder` 가 **브라우저에서 그대로 동작한다.** 이 앱 규모에서는
  백엔드가 아예 필요 없다.
- JavaScript 앱키는 도메인 제한이 걸리는 공개키라, 프런트에 노출돼도 설계상 문제가 아니다.
- 무료 쿼터 안에서 비용 0원. 이 앱의 예상 사용량은 쿼터 근처에도 가지 않는다.

차선은 Naver(사업자 정책·공공 데이터 연계가 걸릴 때), 해외 주소까지 봐야 하면 Google 이다.

| --- | --- | --- | --- | --- | --- |
| **Kakao Maps** (지도 SDK + 로컬 API) | 계정당 **첫 활성화 앱 1개**에 무료 쿼터 (일별 쿼터. 2026-07-21 부터 비즈월렛 연결 방식) | 초과 시 비즈월렛 연결 후 종량 과금 (공개 단가표 없음) | 최상 (도로명·지번·건물명·상호) | JS 앱키 + 도메인 제한 (공개키) | **불필요** |

| VWorld (국토부) | 지도 무료 / 지오코더 일 40,000건 | 무료 (초과 시 별도 신청) | 최상 (정부 원본 데이터) | 발급 키 + 도메인 등록 | 경우에 따라 |

## 사용량이 늘면

볼륨 할인 미반영, 지도 로드와 지오코딩을 함께 계산한 월 비용이다.

| 후보 | 소규모 (지도 3천 · 지오코딩 1만) | 중간 (지도 10만 · 지오코딩 30만) | 대규모 (지도 100만 · 지오코딩 300만) |
| --- | --- | --- | --- |
| Kakao | 0원 | 0원 | 유료 전환 (단가 비공개) |
| Naver | 0원 | 0원 | 0원 (무료 한도 안) |
| Google | $0 | 약 $2,080 | 약 $21,880 |
| Mapbox | $0 | 약 $400 | 약 $5,975 |

소규모 구간에서는 넷 다 0원이다. 그래서 **이 앱의 선택 기준은 가격이 아니라 한국 주소
정확도와 백엔드 필요 여부**였다. 가격은 사용량이 예상 밖으로 커졌을 때 어디서 무너지는지를
보는 용도로만 의미가 있고, 그 지점에서 Google 이 가장 빨리 비싸진다.

## 후보별 제약

### Kakao Maps — 채택

- 강점: 도로명·지번·건물명·상호를 한 API 로 검색. `services.Geocoder.addressSearch()` 가
  브라우저에서 그대로 동작해 서버가 필요 없다.
- 제약: 무료 쿼터가 **개발자 계정의 첫 활성화 앱 1개**에만 붙는다. 이미 다른 앱에 쿼터를
  쓰고 있다면 그 앱을 옮기거나 비즈월렛을 연결해야 한다.
- 주의: 지오코딩 결과를 DB 에 대량 적재해 두는 용도는 약관 해석이 갈린다. 이 앱은 화면
  표시용 일회성 변환이라 해당하지 않는다.

### Naver Maps — 차선

- 강점: 무료 한도가 압도적. 지오코딩 월 300만건까지 0원.
- 제약: Geocoding API 가 **CORS 를 허용하지 않는다.** 브라우저에서 직접 못 부르고, 비밀키를
  쥔 서버 프록시를 반드시 둬야 한다. 이 앱에 백엔드가 생기는 유일한 이유가 된다.
- 주의: 무료 한도는 조직당 대표 계정 1개 기준.

### Google Maps — 해외용

- 강점: 해외 주소까지 한 번에 처리. 문서와 타입 정의가 가장 잘 정리돼 있다.
- 제약: 한국 지번 주소와 신축 건물에서 실패율이 눈에 띈다. 이 앱은 실패한 주소를 사용자에게
  되돌려 줘야 하는데, 그 목록이 길어진다.
- 주의: 결제 수단 등록 필수. 무료 한도를 넘기면 단가가 가장 높다.

### Mapbox — 부적합

- 한국 도로명주소 지오코딩 커버리지가 이 앱의 핵심 기능을 못 받쳐 준다.
- 좌표를 저장하면 임시(temporary)가 아닌 영구(permanent) 지오코딩이라 무료 구간이 사라진다.

### Leaflet + Nominatim — 부적합

- Nominatim 공용 서버는 **초당 1회**가 절대 상한이고, 여러 주소를 한 번에 넣는 방식은
  정책이 금지하는 '체계적 조회'에 해당한다. 자동완성은 즉시 차단 사유.
- 제대로 쓰려면 Nominatim 을 직접 띄워야 하는데, 그 순간 이 앱보다 운영이 무거워진다.

### VWorld — 보조

- 국토교통부 원본 주소 데이터라 도로명주소 정확도가 최상이고 완전 무료.
- 지오코더가 일 40,000건 제한. 초과분은 홈페이지에서 별도 신청.
- 주 API 가 못 찾은 주소를 다시 시도하는 **2차 폴백**으로 두면 실패 목록을 줄일 수 있다.
