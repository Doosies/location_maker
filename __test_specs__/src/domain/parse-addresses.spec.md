# 붙여넣은 텍스트를 주소 줄로 나누기

사람들은 주소를 손으로 치지 않는다. 엑셀의 주소 열을 통째로 복사해 붙여넣는다. 그래서
들어오는 문자열에는 따옴표, 번호 접두사, CRLF, 빈 줄이 섞여 있다.

**줄 하나가 항목 하나다.** 정규화하면 같아지는 줄이 둘 있어도 항목은 둘로 남는다 —
목록 순서와 마커 번호가 입력 줄 순서와 끝까지 같아야 하기 때문이다. 같은 주소를 두 번
조회하지 않는 일(중복 접기)은 목록에서 줄을 지우는 것이 아니라 큐에서 결과를 나눠 쓰는
방식으로 한다. 그래서 파싱은 `normalized` 를 같이 돌려주고, 판단은 큐가 한다.

### UC-LM-PARSE-001 줄마다 항목 하나를 만든다

- **Given** 줄바꿈으로 구분된 주소 세 줄이 있고
- **When** 파싱하면
- **Then** 항목이 셋이고 순서가 입력과 같으며 전부 `pending` 이다

### UC-LM-PARSE-002 빈 줄과 공백만 있는 줄은 버린다

- **Given** 주소 사이에 빈 줄과 공백만 있는 줄이 섞여 있고
- **When** 파싱하면
- **Then** 그 줄들은 항목이 되지 않는다

### UC-LM-PARSE-003 앞뒤 공백을 트림한다

- **Given** 주소 앞뒤에 공백과 탭이 붙어 있고
- **When** 파싱하면
- **Then** `raw` 에 트림된 값이 담긴다

### UC-LM-PARSE-004 엑셀에서 딸려온 큰따옴표를 뗀다

- **Given** 줄이 `"서울 …"` 처럼 큰따옴표로 감싸여 있고
- **When** 파싱하면
- **Then** 따옴표가 빠진 주소가 남는다

### UC-LM-PARSE-005 번호 접두사를 뗀다

- **Given** 줄이 `1. `, `1) `, `1 - ` 같은 번호로 시작하고
- **When** 파싱하면
- **Then** 번호가 빠진 주소가 남는다

### UC-LM-PARSE-006 번지수는 번호 접두사로 오해하지 않는다

- **Given** 줄이 `123-45 어딘가` 처럼 숫자로 시작하는 주소이고
- **When** 파싱하면
- **Then** 숫자가 그대로 남는다

### UC-LM-PARSE-007 CRLF 를 LF 와 같게 다룬다

- **Given** 줄 구분이 `\r\n` 이고
- **When** 파싱하면
- **Then** `\n` 으로 구분한 것과 같은 결과가 나온다

### UC-LM-PARSE-008 같은 주소가 두 줄이어도 항목은 둘이다

- **Given** 정규화하면 같아지는 줄이 둘 있고
- **When** 파싱하면
- **Then** 항목이 둘이고, 각자의 `raw` 를 그대로 들고 있으며, `normalized` 가 서로 같다

### UC-LM-PARSE-009 id 는 줄마다 다르다

- **Given** 원문이 완전히 같은 줄이 둘 있고
- **When** 파싱하면
- **Then** 두 항목의 `id` 가 서로 다르다

### UC-LM-PARSE-010 빈 입력은 빈 배열이다

- **Given** 입력이 빈 문자열이거나 공백·줄바꿈뿐이고
- **When** 파싱하면
- **Then** 빈 배열이 나온다
