# 지도 범위 계산

찍힌 마커 전체가 한눈에 들어오도록 지도를 맞춘다. 계산은 SDK 를 모르는 순수 함수라
브라우저 없이 테스트한다 — SDK 를 부르는 일은 훅이 따로 한다.

**함정은 폭이 0 인 범위다.** 점 하나짜리 bounds 를 SDK 에 넘기면 최대 배율까지
끌어당긴다. 건물 한 채가 화면을 가득 채우면 그게 어디인지 알 수 없다.

### UC-LM-BOUNDS-001 마커가 없으면 아무것도 하지 않는다

- **Given** 좌표가 하나도 없고
- **When** 범위를 계산하면
- **Then** `kind: 'none'` 이다

첫 진입에서 지도를 엉뚱한 곳으로 옮기지 않는다.

### UC-LM-BOUNDS-002 마커가 하나면 중심과 고정 레벨을 쓴다

- **Given** 좌표가 하나 있고
- **When** 범위를 계산하면
- **Then** `kind: 'center'` 와 고정 레벨이 나온다

### UC-LM-BOUNDS-003 마커가 여럿이면 전부 포함하는 범위를 낸다

- **Given** 서울 둘과 부산 하나가 있고
- **When** 범위를 계산하면
- **Then** 남·서·북·동 끝이 그 셋을 모두 감싼다

### UC-LM-BOUNDS-004 좌표가 전부 같으면 마커가 여럿이어도 중심을 쓴다

- **Given** 같은 좌표가 두 개 있고
- **When** 범위를 계산하면
- **Then** `kind: 'center'` 다

같은 건물을 두 줄로 적은 경우다. 개수만 보고 bounds 를 쓰면 마커 하나일 때와 똑같은
최대 배율 문제가 그대로 난다.

### UC-LM-BOUNDS-005 위도만 같고 경도가 다르면 범위를 쓴다

- **Given** 위도가 같고 경도가 다른 좌표 둘이 있고
- **When** 범위를 계산하면
- **Then** `kind: 'bounds'` 다

한 축만 0 인 것은 문제가 아니다. 이 경우까지 중심으로 처리하면 동서로 떨어진 두 곳이
한 점으로 접힌다.
