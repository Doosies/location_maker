# 지도 화면

SDK 를 주입받아 지도를 만들고 마커를 맞춘다. 테스트는 **무엇을 시켰는지만 기록하는
가짜 SDK** 로 돈다 — 실제 지도를 그리지 않고 네트워크도 키도 쓰지 않는다.

### UC-LM-MAP-001 찾은 항목마다 마커를 올린다

- **Given** `found` 하나와 `notFound` 하나가 있고
- **When** 지도를 렌더하면
- **Then** 오버레이가 하나 만들어져 지도에 붙는다

### UC-LM-MAP-002 마커에 목록 자리 번호가 찍힌다

- **Given** 첫째가 실패하고 둘째가 `found` 이며
- **When** 지도를 렌더하면
- **Then** 그 마커의 내용이 **2** 다

실패한 줄이 1번을 차지한다. 이것이 목록과 지도를 눈으로 짝지을 유일한 단서다.

### UC-LM-MAP-003 마커가 하나면 범위 대신 중심과 고정 레벨을 쓴다

- **Given** `found` 가 하나 있고
- **When** 지도를 렌더하면
- **Then** 그 좌표로 중심이 옮겨지고 레벨이 고정값이다

### UC-LM-MAP-004 마커가 여럿이면 전부 담는 범위를 만든다

- **Given** 서울과 부산에 하나씩 있고
- **When** 지도를 렌더하면
- **Then** 남서 · 북동 두 점이 bounds 에 들어간다

### UC-LM-MAP-005 항목이 늘어도 기존 마커를 다시 만들지 않는다

- **Given** 마커 하나가 이미 올라가 있고
- **When** 항목이 하나 늘어 다시 렌더되면
- **Then** 오버레이는 둘만 만들어진다 (기존 것을 다시 만들지 않는다)

조회는 한 건씩 끝난다. 매번 다시 그리면 열 줄짜리 입력에서 마커가 열 번 깜빡인다.

### UC-LM-MAP-006 고른 항목의 마커로 지도를 옮긴다

- **Given** 마커가 둘 있고
- **When** 둘째를 고르면
- **Then** 그 좌표로 `panTo` 한다

### UC-LM-MAP-007 언마운트하면 마커를 걷어 낸다

- **Given** 마커가 올라가 있고
- **When** 지도를 언마운트하면
- **Then** 오버레이가 모두 지도에서 내려간다

남겨 두면 다음 지도에 유령 마커가 뜬다.

### UC-LM-MAP-008 키가 없으면 지도 대신 안내를 띄운다

- **Given** 키가 빈 문자열이고
- **When** 지도를 렌더하면
- **Then** 넣어야 할 변수 이름이 담긴 안내가 보인다

흰 화면이 되면 설정이 빠진 것과 코드가 깨진 것을 구분할 수 없다.
