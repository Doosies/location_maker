# CSV 내보내기

문자열만 만든다. 파일로 건네는 일은 `download.ts` 가 하므로 이 파일은 DOM 없이 테스트된다.

플랜의 `건물명` 열 대신 `도로명주소` 를 쓴다. 어댑터가 들고 오는 것은 지번 주소(`label`)
와 도로명 주소(`roadAddress`) 둘이고, 장소명으로 찾은 경우에만 `label` 이 상호가 된다.
없는 열을 만들기보다 있는 것을 그대로 내보낸다.

### UC-LM-CSV-001 머리글과 항목 줄을 순서대로 낸다

- **Given** 찾은 항목과 못 찾은 항목이 있고
- **When** CSV 로 만들면
- **Then** 머리글 다음에 입력 순서대로 줄이 온다

### UC-LM-CSV-002 실패한 줄도 자리와 상태를 지키고 들어간다

- **Given** 못 찾은 항목이 있고
- **When** CSV 로 만들면
- **Then** 그 줄이 순번과 상태를 달고 빠짐없이 들어간다

화면과 같은 원칙이다. 스무 줄을 넣었는데 열여덟 줄만 있으면 어느 둘이 빠졌는지 사용자가
원본과 대조해야 한다.

### UC-LM-CSV-003 한글이 깨지지 않게 BOM 을 붙인다

- **Given** 한글이 든 결과가 있고
- **When** CSV 로 만들면
- **Then** 맨 앞에 BOM 이 있다

엑셀은 BOM 이 없는 UTF-8 CSV 를 지역 인코딩으로 읽는다. 세 글자로 파일 하나가 살거나 죽는다.

### UC-LM-CSV-004 쉼표·따옴표·줄바꿈이 든 값을 감싼다

- **Given** 셋이 각각 든 주소가 있고
- **When** CSV 로 만들면
- **Then** 따옴표로 감싸이고 안쪽 따옴표는 두 번 겹친다 (RFC 4180)

주소에는 셋 다 흔하다. 감싸지 않으면 열이 밀려 좌표가 엉뚱한 칸에 들어간다.

### UC-LM-CSV-005 파일명에 날짜가 들어간다

- **Given** 어느 날짜가 있고
- **When** 파일명을 만들면
- **Then** `location-maker-YYYY-MM-DD.csv` 다

같은 폴더에 여러 번 받아도 덮어쓰지 않는다.
