# 키 없이 빌드된 화면

키 주입은 **빌드 타임**이라 키가 있는 화면과 없는 화면은 서로 다른 번들이다. 그래서 이
파일만 다른 서버(4174)를 본다. 배포가 키 없이 나갔을 때 사용자가 무엇을 보는지는 여기서만
확인된다.

### UC-LME-NOKEY-001 키가 없으면 지도 자리에 넣을 변수 이름이 보인다

- **Given** 키 없이 빌드된 화면을 열고
- **When** 지도 자리를 보면
- **Then** `LOAD_FAILURE_MESSAGE['no-key']` 문구가 그대로 보인다 (`script` 실패 문구에도
  같은 변수 이름이 들어 있어, 이름만 찾으면 원인이 달라도 통과한다)

흰 화면이 되면 설정이 빠진 것과 코드가 깨진 것을 구분할 수 없다.

### UC-LME-NOKEY-002 키가 없어도 입력과 목록은 그대로 돈다

- **Given** 키 없이 빌드된 화면에서
- **When** 주소를 넣고 조회하면
- **Then** 목록이 한 줄 만들어진다

지도를 못 띄우는 것과 앱이 멈추는 것은 다르다.
