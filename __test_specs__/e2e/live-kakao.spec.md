# 진짜 SDK 로 한 번

스텁 저니만 있으면 **"우리 코드는 맞는데 SDK 계약이 바뀐"** 경우를 영영 못 잡는다.
반대로 이것을 CI 에 넣으면 남의 서비스가 느린 날 우리 CI 가 빨개진다. 그래서 따로 두고
`pnpm test:e2e:live` 로 수동 실행한다.

키가 없으면 **실패한다.** 조용히 건너뛰면 초록이 신호가 아니게 된다. 쿼터를 축내지 않도록
주소는 하나만 쓴다.

### UC-LME-LIVE-001 진짜 SDK 가 준 좌표가 한국 안에 있다

- **Given** 진짜 키로 빌드된 화면을 열고
- **When** 주소 하나를 조회한 뒤 CSV 를 받아 좌표를 보면
- **Then** 위도·경도가 남한을 감싸는 범위 안이다

진짜 지도의 마커에서는 좌표를 읽을 수 없어 CSV 로 확인한다. `x`/`y` 를 뒤집었으면
여기서 드러난다.
