# 붙여넣기부터 CSV 까지

단위 테스트는 부분이 맞는지 보고, 이 저니는 **부분들이 이어지는지** 본다. 빌드된 번들,
base 경로, SDK 로더, 클립보드, 내려받기는 여기서만 함께 돈다.

SDK 요청은 가로채 고정 응답을 준다. CI 에서 진짜 SDK 를 쓰면 테스트가 남의 서비스의
네트워크와 쿼터에 묶이고, 카카오가 느린 날 우리 CI 가 빨개진다. 계약이 바뀌는 경우는
스텁으로 잡을 수 없으므로 `live-kakao.test.ts` 를 따로 둔다.

### UC-LME-PLOT-001 주소 다섯 개를 넣으면 마커 다섯 개가 목록 순서대로 찍힌다

- **Given** 스텁이 아는 주소 다섯 줄이 있고
- **When** 붙여넣고 `지도에 표시` 를 누르면
- **Then** 마커가 다섯이고 번호가 1부터 5까지 순서대로다

목록 자리 번호 = 마커 번호. 이 불변식이 화면 전체를 지나 살아 있는지 보는 자리다.

### UC-LME-PLOT-002 못 찾는 주소는 제자리에 남고 마커만 그만큼 적다

- **Given** 첫 줄이 스텁에 없는 주소이고
- **When** 조회가 끝나면
- **Then** 그 줄이 목록 첫 자리에 원문 그대로 남고, 마커는 하나이며 번호가 **2** 다

### UC-LME-PLOT-003 고쳐서 다시는 그 줄을 입력창에서 골라 준다

- **Given** 실패한 줄이 입력창에 그대로 있고
- **When** `고쳐서 다시` 를 누르면
- **Then** 입력창 내용은 그대로이고 그 줄이 선택된다

### UC-LME-PLOT-004 중단을 누르면 멈추고 남은 줄이 대기로 남는다

- **Given** 응답이 느려 조회가 도는 중이고
- **When** `중단` 을 누르면
- **Then** `지도에 표시` 가 다시 눌리는 상태가 되고 남은 줄이 `대기` 로 남는다

### UC-LME-PLOT-005 링크를 복사해 열면 같은 목록이 복원되고 저절로 조회된다

- **Given** 입력창에 주소 둘이 있고
- **When** `링크 복사` 로 얻은 주소를 새 탭에서 열면
- **Then** 같은 목록이 복원되고 버튼을 누르지 않아도 마커 둘이 찍힌다

### UC-LME-PLOT-006 CSV 를 내려받으면 입력 줄 수만큼 줄이 들어 있다

- **Given** 찾은 줄과 못 찾은 줄이 하나씩 있고
- **When** `CSV 내려받기` 를 누르면
- **Then** 날짜가 붙은 파일이 받아지고 머리글 + 두 줄이며 실패한 줄도 들어 있다

### UC-LME-PLOT-007 장소명으로만 찾히는 줄도 마커가 된다

- **Given** 주소 검색으로는 안 나오고 키워드로만 나오는 줄이 있고
- **When** 조회하면
- **Then** `장소명으로 찾음` 이 보이고 마커가 하나 찍힌다

어댑터의 폴백 경로가 실제 화면까지 이어지는지 보는 자리다.
